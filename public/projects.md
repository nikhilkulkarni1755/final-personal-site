### Iridium

Agent-native LinkedIn access. An MCP server giving any agent live profile and post data plus real actions — comments, DMs, connection requests, scheduled posts. 50+ tools across prospecting, inbox triage, commenting, and content, with user approval required before anything sends, server-side rate limits, and a full activity log. Built and shipped end to end.

MCP Agent Orchestration Human-in-the-Loop Tool-Calling Design OAuth Multi-Tenant FastAPI PostgreSQL Evals

[Connect to Claude](https://iridiumhqmcp.com)

### Iridium Agent

Open-source chat agent that drives Iridium over MCP. Two states driven by the live connection: unauthenticated it can only describe the toolset and hand back a signup link, never pretending to act; once the server reports ready, every live tool flows in automatically. That state machine is the architecture.

Cloudflare Agents MCP Client Durable Objects Workers AI OAuth TypeScript

[View on GitHub](https://github.com/nikhilkulkarni1755/iridium-agent)
