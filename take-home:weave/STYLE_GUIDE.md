Here's the full inventory of design components and the design system:

--- Fonts (3 Google Fonts): - Playfair Display (serif, weight 700/900) — the authoritative font used for the main title, all h2 section titles, and h3 subtitles. It's a high-contrast serif that looks editorial/magazine-like. The & you noticed looking fun is Playfair's italic ampersand, which has a calligraphic flourish. - DM Mono (monospace) — used for code/math blocks, labels, section tags (Chapter 01), table headers, TOC chips, buttons, and the eyebrow badge. Gives everything a technical/terminal feel. - DM Sans (sans-serif) — used for body text and small descriptors inside architecture blocks. Color palette (4 accents): - #7c6aff (purple) — primary accent, used for links, highlights, section tags - #6affe0 (teal/green) — subtitles, green variant blocks, GPU done state - #ff6a9a (pink) — warnings, multiplication symbols, pink variant blocks - #ffc96a (yellow) — yellow variant blocks, flow box variant Components list: 1. Hero title — Playfair Display at clamp(3rem, 8vw, 5rem), weight 900. Matrices is wrapped in <em> which gives it Playfair's italic + colored #7c6aff. Rest is default color. 2. Eyebrow badge — small monospace pill with border + tinted background (Complete Technical Deep-Dive) 3. TOC chips — horizontal flex-wrap row of small monospace anchor links with borders, hover turns purple 4. SectionTag — CHAPTER 01 in tiny tracked monospace, with a gradient line extending to the right (fade from purple to transparent) 5. MathBlock — rounded box with colored left border (3px), a floating label badge in top-right corner (colored pill), monospace <pre> content inside. 4 color variants (purple/green/pink/yellow) 6. Callout — rounded box with colored left border, emoji + bold prefix (Key Insight —), tinted background. 3 types (insight/warning/gpu) 7. ArchDiagram + ArchBlock + ArchArrow — vertical stack of rounded boxes connected by gradient arrows with ▼ triangles. Each block has a label + small descriptor. Blocks can be colored (accent/green/pink/yellow) or default. This is the pipeline/layer diagram pattern. 8. FlowDiagram + FlowBox + FlowArrow — horizontal (or vertical) chain of small boxes connected by → arrows. Used for tokenization pipeline, forward pass flow. Boxes can be highlighted in 3 variants. 9. Matrix + Cell — matrix bracket styling using CSS pseudo-elements (absolute positioned border segments creating [ and ]). Cells are 44×44px rounded squares with monospace numbers. Cells can be highlight (purple glow) or resultHighlight (teal glow). 10. CompareTable — full-width table with monospace uppercase purple headers, hover row highlight, first column bold 11. 3 Interactive demos — each wrapped in a container with a dark header bar (monospace label + button) and body area
